# Feedback System — Beta

Channels to collect feedback:
- In-app feedback form → webhook to `contact_submissions` or dedicated `feedback` table.
- Email: feedback@fundedwealth.example
- Short survey link after challenge completion.

Triage categories:
- Bug report — requires reproduction steps
- Feature request — product team review
- Complaint — customer service resolution required

Bug report template (to collect from users/support):
- Summary:
- Steps to reproduce (exact):
- Expected behavior:
- Actual behavior:
- Browser / OS / App version:
- Screenshots / recordings:
- User id / email:

Feature request template:
- Title:
- Problem being solved:
- User benefit:
- Suggested priority:

Recording & triage process:
- All entries get a ticket in the support system with tag `feedback`.
- Triage daily: support labels as `bug`, `feature-request`, or `complaint` and assigns owner.
- Product reviews feature-requests weekly.

Reporting:
- Weekly feedback digest: top 5 bugs, top 5 feature requests, open complaints.
